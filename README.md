# 楽天市場 競合分析ツール

自分の売れ筋商品名で楽天市場を検索し、競合商品の**価格・レビュー・ポイント・送料**を分析してCSV/Excelに出力するツールです。

## セットアップ

### 1. 楽天APIキーの取得（無料）

1. [楽天ウェブサービス](https://webservice.rakuten.co.jp/) にアクセス
2. アプリIDを発行（無料、すぐ取得可能）

### 2. インストール

```bash
pip install -r requirements.txt
cp .env.example .env
# .env ファイルを編集して RAKUTEN_APP_ID を設定
```

## 使い方

### 基本的な使い方

```bash
# 1つのキーワードで検索
python rakuten_research.py "ワイヤレスイヤホン"

# ソート順を指定（レビュー多い順）
python rakuten_research.py "ワイヤレスイヤホン" --sort -reviewCount

# 取得ページ数を増やす（1ページ=30件）
python rakuten_research.py "ワイヤレスイヤホン" --pages 3
```

### 複数キーワードを一括検索

```bash
# キーワードファイルを作成（1行1キーワード）
echo "ワイヤレスイヤホン
モバイルバッテリー
スマホケース" > keywords.txt

python rakuten_research.py --file keywords.txt
```

### ソートオプション

| オプション | 説明 |
|---|---|
| `standard` | 楽天標準（デフォルト） |
| `-reviewCount` | レビュー件数多い順 |
| `+itemPrice` | 価格安い順 |
| `-itemPrice` | 価格高い順 |
| `-updateTimestamp` | 更新日時新しい順 |

## 出力内容

### コンソール出力
- 競合状況サマリー（価格帯、レビュー数、送料無料率など）
- 上位10商品の一覧表
- 売れている要因の自動分析

### Excel出力（output/フォルダ）
- **商品一覧シート**: 全商品の詳細データ
- **競合分析サマリーシート**: 統計データ
- **価格帯分析シート**: 価格帯別の商品分布

### CSV出力
- 全商品データのCSV（Excel等で開いてさらに分析可能）

## 分析できる項目

| 項目 | 説明 |
|---|---|
| 価格 | 販売価格 |
| 実質価格 | ポイント分を差し引いた実質的な価格 |
| 送料 | 送料無料/送料別 |
| レビュー件数 | レビューの数（多いほど売れている） |
| レビュー評価 | 平均評価（5点満点） |
| ポイント倍率 | ポイント付与倍率 |
| ショップ名 | 出品ショップ |
